# תת-נושא 7: חישוב קצב שינוי — (הפרש ב-y) חלקי (הפרש ב-x)

הנוסחה לחישוב קצב שינוי בין שתי נקודות:
$$m = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$$
